# Session Start Checklist

Every new agent must:

1. Read `AGENTS.md`.
2. Read `README.md`.
3. Read `.ai/PROJECT_STATUS.md`.
4. Read `.ai/CURRENT_TASK.md`.
5. Run `git status`.
6. Run `git diff`.
7. Read relevant module README files.
8. Read relevant ADRs.
9. Read relevant tests.
10. Determine whether unfinished work already exists.

> Do not start unrelated new work while `CURRENT_TASK.md` describes partially completed implementation without first determining whether the existing task must be continued, suspended, or reverted.

> Never discard uncommitted changes without explicit authorization.

Search for equivalent code before creating abstractions. Confirm the requested work's acceptance criteria, security impact, platform impact, and appropriate verification before editing.
