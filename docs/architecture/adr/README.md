# Architecture Decision Records

ADRs preserve significant architectural choices, their context, alternatives, and consequences. IDs use `ADR-0001`, `ADR-0002`, and so on and are never reused. A later decision supersedes an old ADR rather than rewriting history.

Statuses are **Proposed**, **Accepted**, **Superseded**, or **Rejected**.

```md
# ADR-XXXX — Title

## Status

Proposed / Accepted / Superseded / Rejected

## Context

...

## Decision

...

## Alternatives Considered

...

## Consequences

...
```
